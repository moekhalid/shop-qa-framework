
# Selenium Python QA Automation Framework

This project is a web automation testing framework built using Python, Selenium WebDriver, and pytest.

## Technologies Used
- Python
- Selenium WebDriver
- pytest
- Page Object Model (POM)
- Git and GitHub

## Project Features
- Automated login testing
- Positive and negative test scenarios
- Data-driven testing using CSV and JSON
- Shopping cart testing
- Checkout process automation
- Reusable browser fixtures
